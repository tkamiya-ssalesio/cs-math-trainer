# CS Math Trainer | 情報I 計算トレーニングアプリ

高校の「情報I」の授業で学習する、**進数計算**やデジタルデータに関する計算のトレーニングを行うためのWebアプリケーションです。インストールや複雑な設定は一切不要で、Webブラウザさえあれば即座に実行・学習を開始できます。

---

## 🚀 特徴

- **豊富な進数変換モード**
  - 2進数 ➔ 10進数 
  - 10進数 ➔ 2進数 (ビットを直接ON/OFFできる**インタラクティブなトグルスイッチUI**を搭載)
  - 10進数 ➔ 16進数
  - 16進数 ➔ 10進数
  - 2進数 ➔ 16進数
  - 16進数 ➔ 2進数 (ビットを直接ON/OFFできる**インタラクティブなトグルスイッチUI**を搭載)
- **2進数の計算（足し算・補数）**（4つ目のカテゴリ。詳しくは下の「2進数の計算（足し算・補数）」）
  - 足し算の筆算／補数を求める／補数を使った引き算を、**1段ずつ・1ビット1マス**で入力して練習（解説つき）
  - **時間制限・コンボなし**。難易度は**初級（4ビット）と中級（8ビット）だけ**
- **2進数の小数**（5つ目のカテゴリ。詳しくは下の「2進数の小数」）
  - 10進数→2進数（×2 の縦計算）と、2進数→10進数（位取りの表）を、**1段ずつ**入力して練習（解説つき）
  - **時間制限・コンボなし**。難易度は**初級（小数第4位まで）と中級（整数部分つき）だけ**
- **3つの難易度設定**（既存の3カテゴリ。「2進数の計算（足し算・補数）」と「2進数の小数」では初級・中級の2つだけで、上級は選べません）
  - **初級 (4-bit / 0〜15)**: 初めて進数計算を学ぶ生徒向け。
  - **中級 (8-bit / 16〜255)**: 標準的な計算練習用。1バイトの構成を理解するのに最適。
  - **上級 (16-bit / 256〜65535)**: より複雑な計算に挑戦したい生徒向け。
- **ゲーム性を持たせた学習体験**
  - 各問題15秒の時間制限があり、素早い計算力を養います（「2進数の計算（足し算・補数）」には時間制限・コンボはありません）。
  - 連続正解で「コンボ」が発生し、獲得スコアがアップします。
  - 終了後は間違えた問題が一覧で表示され、その場で復習できます。
- **授業への導入が非常に簡単**
  - HTML/CSS/JavaScriptのみで構築されているため、ビルド不要でGitHub Pages等に配置するだけで、生徒の端末（Chromebook、iPad、Windows/Mac）からアクセス可能です。

## 2進数の計算（足し算・補数）

情報Ⅰ「情報のデジタル表現」の「2進数の足し算と補数」の練習用カテゴリです（メニューの4つ目のカード）。もとは単独のアプリ（binary-calc-drill）として作ったものを、このアプリに組み込みました。

**何を固定し、何を変えるか**: 2進数の足し算（筆算）と補数（補数を使った引き算）を、教科書どおりの手順で、1段ずつ答えて練習します。固定するのは手順の段（繰り上がり → 答え、反転 → 1を足す → 補数を足す → はみ出した桁を無視、など）と補数の定義、変えるのは2進数の値（4ビットか8ビット、繰り上がりの連なり方）だけです。

### 生徒向け

- メニューで「2進数の計算（足し算・補数）」を選び、難易度（初級＝4ビット／中級＝8ビット）を選んでから、次の4つを選びます。
  - **解説**: 補数とは何か → 10進数の補数のイメージ（74の補数は26）→ 2進数の補数（問い：引き算を使わずに求められないか）→ 2進数の補数の求め方（反転して1を足す。10進数の補足つき）→ 検算 → 補数を使った引き算の考え方（走行距離計の例）を、ステップごとに見ます。
  - **足し算の筆算**: 繰り上がりの行 → 答えの行、の2段。
  - **補数を求める**: 反転 → 1を足す、の2段。最後に検算（もとの数＋補数＝10…0）が出ます。
  - **補数を使った引き算**: 反転 → 1を足す（補数）→ 補数を足す → はみ出した桁を無視、の4段。最後に10進数で確かめます。
- **補数**: ある数に対し、足すと1桁増える最も小さな数。2進数の補数は、各桁の0と1を反転して1を足して求めます。
- **補数を使った引き算**: ① 引く数の補数を足す → はみ出した桁を無視 → ② 10進数で確かめる。
- 各段は「答え合わせ」ボタンか Enter キーで確かめます。マスは1ビット1マスで、0 と 1 だけ入ります（全角の０１も可）。1文字ずつ打つと右端のマスから入って左へ進みます（既定）。まとめて入れたとき（IME の確定など）は、読む順（左から右）に配り、そのあと打つ1文字も右へ進みます（行末で止まる）。まとめて入れた0・1の数がその行のマス数以上なら、いつも左端のマスから入って行全体が置き換わります（入っていた値は上書き。空きを残して答え合わせをしたあとでも、途中まで入れたあとでも同じ）。マス数より少ないときは、直前にまとめて入れた続きで、フォーカスのマス以降（フォーカスのマス自身を含む）に空きがあるときだけフォーカスのマスから入り（4桁ずつ2回に分けて確定すると、2回目は続きのマスから入ります。前の分は消えません）、それ以外は左端から入ります。Enter でも「答え合わせ」ボタンでも、空きがあって断られたあとは同じ状態（右端から見て最初の空きのマスから、1文字ずつ打つ既定）に戻ります。Backspace で行が空になる、Home・End を押す、マスをクリックする、段が変わる、答え合わせのあと赤いマスに戻る、のどれかで既定（右端から左へ）に戻ります。← → Home End で移動、Backspace で消します。Tab は行全体で1停止です。
- 1回目に間違えたら、赤いマスと「右から2桁目と4桁目がちがいます」の文が出て、もう1回できます。ヒントは1つだけです。2回目も間違えたら、正しい値が出て次の段へ進みます（次の段は正しい値の上から始まるので、間違いが続きません）。
- 段のチップ（✓／×／—）で、どの段で間違えたかが分かります。
- 1回目で全段正解した問題が続くと ✓（足し算の筆算と補数は3問、補数を使った引き算は2問）。✓ はサブメニューのカードに初級・中級ごとに小さく出ます。
- 「ことば」に補数の定義、「きみの記録」に段ごとの回数・1回目の誤り・割合が出ます。

### 教員向け

- **時間制限・タイマー・コンボ・スコアはありません**。ゆっくり考えて答える練習です。
- **難易度は初級（4ビット）と中級（8ビット）だけ**です（上級の16ビットは選べません）。
- 記録（連続・✓・段ごとの誤り）は、その端末のブラウザの中だけに残ります（localStorage のキー `csMathTrainer.binaryCalc.v1`。5つ目のカテゴリ「2進数の小数」は別のキー `csMathTrainer.binaryFraction.v1` に記録を残します。既存の3カテゴリは localStorage を使いません）。アカウントも教員画面もありません。「記録を消す」で初期化できます（このカテゴリの記録だけが消えます。消したあとも、選んでいた種類・難易度は保たれます）。**共用の端末は、次の人に渡す前に、4つ目と5つ目のカテゴリでそれぞれ「記録を消す」を押してください。** localStorage が使えない端末でも動きます（そのときは小さく「この端末では記録を残せません」と出ます）。
- 「全部クリア」の判定はありません。✓ はサブメニューのカードに初級・中級ごとに出るだけです。
- 「問題を解き終わらずに種類・難易度を替える、または戻る、再読み込みする」と、その種類×難易度の連続は 0 に戻ります。
- 新しいファイルは外部と通信しません（ライブラリも使いません）。
- 追加・変更したファイル: `binary-calc-core.js`（生成・判定・記録。画面に触れない）、`binary-calc.js`（画面）、`binary-calc.css`、`docs/binary-calc-SPEC.md`（設計）、`test/binary-calc-selftest.js`（node 用の検査）、`test/binary-calc-e2e.py`（実ブラウザの入力経路の検査）。既存の `app.js`・`generators.js`・`style.css` は変更していません。`index.html` にメニューのカード・3つの画面・読み込みを足しています。

## 2進数の小数

情報Ⅰ「情報のデジタル表現」の「2進数の小数」（数値の計算②の大問2・3）の練習用カテゴリです（メニューの5つ目のカード）。**授業の時間には使わず**、計算が苦手な人が希望して、あとから練習するための道具です。

**何を固定し、何を変えるか**: 10進数の小数と2進数の小数の変換を、紙の方法どおりに、1段ずつ答えて練習します。固定するのは方法（10進数→2進数は「小数部分に2を掛けることをくり返し、整数部分を上から順に並べる」、2進数→10進数は「1 になっている位の位取りの値を足す」）と、段の手順です。変えるのは変換する数（初級は小数第4位まで、中級は整数部分つき）と、向きです。

### 生徒向け

- メニューで「2進数の小数」を選び、難易度（初級＝小数第4位まで／中級＝整数部分つき）を選んでから、次の3つを選びます。
  - **解説**: 指数が1つ減ると値は半分 → 2⁻¹ から 2⁻⁴ の値 → 2進数の小数の位取り → 2進数→10進数の例 → 10進数→2進数の考え方と例 0.625 → 整数部分があるとき → 終わらない小数（0.1）を、ステップごとに見ます。
  - **10進数→2進数**: ×2 の縦計算の各行で「×2 の答え」と「整数」を書き、最後に整数を上から順に並べて答え（0.□□□）を書きます。次の行の小数部分は、整数を取った残りがアプリから写ります。中級は、最初に整数部分を2進数にします。
  - **2進数→10進数**: 位取りの表の、1 になっている位に位取りの値（0.5 や 0.125 など）を書き（0 の位は「—」で書かない）、そのあと全部足して10進数にします。
- 各段は「答え合わせ」ボタンか Enter キーで確かめます（どの欄にいても Enter は答え合わせです。ほかの欄が空のときは、空いている欄へ移ります）。
  - 答えのマスは1ビット1マスで、0 と 1 だけ入ります（全角の０１も可）。左から右へ入ります。まとめて入れたとき（IME の確定など）は、読む順に配り、マス数以上なら左端から全体を置き換えます。Backspace で消し、← → Home End で移動します。
  - 数の欄は、数字と「.」だけ入ります（全角の数字も、日本語入力の「。」も可）。「1」「1.0」「1.00」や「.5」「0.50」のように、書き方が違っても値が同じなら正解です。
- 1回目に間違えたら、赤い欄と「「×2 の答え」がちがいます」のような文が出て、もう1回できます。ヒントは1回に1つだけです。2回目も間違えたら、正しい値が出て次の段へ進みます（次の段は正しい値の上から始まるので、間違いが続きません）。このときも、1回目と同じヒントがもう一度添えて出ます。
- 段のチップ（✓／×／—）で、どの段で間違えたかが分かります。
- 1回目で全段正解した問題が3問続くと ✓。✓ はサブメニューのカードに初級・中級ごとに小さく出ます。
- 「ことば」に紙の考え方と位取りの値、「きみの記録」に段ごとの回数・1回目の誤り・割合が出ます。
- 終わらない小数（0.1 など）は、解説で見るだけです。練習には出ません。

### 教員向け

- **時間制限・タイマー・コンボ・スコアはありません**。ゆっくり考えて答える練習です。
- **難易度は初級（小数第4位まで。0.0625〜0.9375 の15通り）と中級（整数部分1〜15つき。15×15通り）だけ**です。
- 用語は第10回の紙とスライドにそろえています（小数部分・整数・整数部分・×2 の答え・位取り・指数が1つ減ると値は半分）。負の指数は授業の［2］で初めて習う内容なので、解説は「2³＝8 → 2²＝4 → 2¹＝2 → 2⁰＝1、指数が1つ減ると値は半分」から始め、そのあとで 2⁻¹ などを使います。
- **判定は文字列を正規形に直して比べます**（先頭と末尾の余分な 0 を取った文字列。Number の小数の計算は使いません）。この単元は「コンピュータは小数を正確に持てない」ことを扱うので、アプリが同じ理由で誤判定しないようにしています。
- 記録（連続・✓・段ごとの誤り）は、その端末のブラウザの中だけに残ります（localStorage のキー `csMathTrainer.binaryFraction.v1`）。アカウントも教員画面もありません。「記録を消す」で初期化できます（この5つ目のカテゴリの記録だけが消えます。消したあとも、選んでいた向き・難易度は保たれます）。別のタブで記録を消したときは、開いているタブも記録を読み直します（消す前の回数を書き戻しません）。**共用の端末は、次の人に渡す前に、4つ目と5つ目のカテゴリでそれぞれ「記録を消す」を押してください。** localStorage が使えない端末でも動きます（そのときは小さく「この端末では記録を残せません」と出ます）。
- 「問題を解き終わらずに向き・難易度を替える、または戻る、再読み込みする」と、その向き×難易度の連続は 0 に戻ります。
- 新しいファイルは外部と通信しません（ライブラリも使いません）。
- 追加したファイル: `binary-fraction-core.js`（生成・判定・記録。画面に触れない）、`binary-fraction.js`（画面）、`binary-fraction.css`、`docs/binary-fraction-SPEC.md`（設計）、`test/binary-fraction-selftest.js`（node 用の検査）、`test/binary-fraction-e2e.py`（実ブラウザの検査）。既存の `app.js`・`generators.js`・`style.css`・`binary-calc*` は変更していません（例外1行：4つ目のカテゴリの自己検査がメニューのカードを4枚と数えていたので、5つ目のカードを数えない書き方に直しました）。`index.html` にメニューのカード・3つの画面・読み込みを足しています。
