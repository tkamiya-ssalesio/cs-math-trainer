### 1.1 保留だった2点（組み込みで決めた既定．博士に確認）

**(a) Minor-C：赤いマスの模範が 1 と 0 で混ざるときの繰り上がりのヒント**
- 1回目の誤りで赤いマスが2つ以上あり，**模範が 1 のマスと 0 のマスが混ざる**とき，「ここには 1 が入る」と断定しない．ヒント **A-c3**「赤いマスを見直そう．すぐ右の桁の和（繰り上がりも足す）が 2 以上なら 1，1 以下なら 0」を出す．
- 赤が1種類だけなら今までどおり：模範がすべて 1 → A-c1「ここには 1 が入る…」，すべて 0 → A-c2「ここは 0…」．
- 同型の見立てがほかにないかを全数で確かめた：マス単位の断定を含むヒントは A-c1・A-c2 だけ（ほかは行全体の型についての文．C-s1 は「左端に 1 が出る」だが，当てはまるのは左端だけが赤のとき）．自己検査の #15 が，4ビットの全問題×全ての答え（足し算 105・補数 14・補数で引き算 98 問．各段の全パターン）と，8ビットの足し算 60 問（繰り上がりの段は 2⁷ 通り全部）・補数で引き算 20 問（標本）で，ヒントの主張が赤いマスの模範と食い違わないことを確かめる．

**(b) 複数桁をまとめて入れたとき**
- **行ごとに入力の向き `dir`（読む順 ltr／既定 rtl）を持つ**（pm-lesson の決定 2026-10-19．qa-scizor 1周目 Minor-2）．
- 2文字以上が一度に来たとき（IME の確定・insertText に近い一括入力）は，**読む順（左から右）に右へ順に配り，向きを ltr にする**．配り始めは，**行が空なら左端，そうでなければフォーカスのマス**．行の長さを超える分は捨てて「入りきらない分は捨てました」と小さく出す．0・1 以外の文字は飛ばして配る．配ったあとのフォーカスは，配ったすぐ右のマス（全部埋まったら右端）．2回に分けて確定しても，前の分は消えない（2回目はフォーカスのマスから続く）．
- **ltr の間**は，1文字入力も右へ進む（行末で止まり，右端のマスを上書きする）．Backspace は，値があればそのマスを消し，空なら左のマスへ戻って消す．
- **rtl（既定）**：1文字ずつ打つと，右端のマスから入って左へ進む（左端では進まず上書き）．0・1 が1文字だけ残る入力（「x1」など）は1文字として扱う．
- **rtl に戻る**：Backspace／Delete で行が空になる（フォーカスは右端へ）・Home／End・マスのクリック（`cellEdit` の `focus` イベント）・段が変わる・答え合わせのあと誤りのマスへ戻る（画面側が `dir` を "rtl" にして渡す）．矢印キー，Enter，捨てる入力（0・1 以外）は向きを変えない．繰り上がりの行（n−1 マス）も和の行（n+1 マス）も同じ規則．
- 行が埋まっていて右端にいるときの2文字以上は，行が空ではないので右端のマスから配り始め，右端の1マスだけ入って，あふれた分は知らせる（左端から打ち直したいときは Home かクリック）．
- `cellEdit(row, event)` は純粋関数のまま（row は `{cells, focus, dir}`，戻り値に `dir`）．自己検査 #12 に「2回に分けて確定」「まとめて入力→1文字ずつ」「Backspace で戻る」「Home・End・クリックで戻る」「矢印は向きを変えない」「繰り上がり行・和の行」「row を書き換えない」を足した．

## 2. 問題の生成規則（移植元 §1 のまま）

ビット数 n は 4（初級）か 8（中級）．値は 0 から 2ⁿ−1 の整数．乱数は `Math.random`（自己検査だけ種つき）．

| 種類 | 出す問題 | 除外 |
|---|---|---|
| 足し算の筆算 | a＋b：a,b は 1 以上，a＋b ≤ 2ⁿ−1（答えが n ビットに収まる） | 0 を足す，答えが n ビットを超える足し算 |
| 補数を求める | x：1 以上 2ⁿ−1 以下，2ⁿ⁻¹ を除く | x＝0（補数が n ビットに収まらない），x＝1000／10000000（補数が自分自身） |
| 補数を使った引き算 | a−b：a > b ≥ 1，b ≠ 2ⁿ⁻¹ | b＝0，b＝2ⁿ⁻¹，a ≤ b |

型の割合（8ビットでも同じ）：足し算 A0（繰り上がりなし）25%／A1（連ならない）40%／A2（連続2回以上）35%．補数 Ba（末尾 1）25%／Bb（末尾 10）25%／Bc（末尾 100 以下）30%／Bd（先頭に 0 が n/2 個以上）20%．補数で引き算は b の型 Ca 40%／Cb 30%／Cc 30%．まず型を割合で決め，その型の中から一様に選ぶ．**同じ問題を連続させない**（直前と同じなら同じ型の中で引き直す）．プールの大きさ（4ビット：A0 50／A1 28／A2 27／Ba 6／Bb 3／Bc 2／Bd 3／Ca 56／Cb 28／Cc 14）は全数列挙で確かめ，自己検査が数え直して照合する．

## 3. 段の一覧と判定

各段の正解は，生徒の前の段の答えではなく**模範の値**で定める．段が解決したら（正解でも，値を見せても）その行は模範の値に差し替えて鍵をかけ，次の段は模範の値の上から始まる．

| 種類 | 段（画面の名前） | 入力欄 |
|---|---|---|
| 足し算の筆算 | 繰り上がり → 答え | n−1 マス → n マス |
| 補数を求める | 反転 → 1を足す（補数）→（検算の表示） | n マス → n マス |
| 補数を使った引き算 | 反転 → 1を足す（補数）→ 補数を足す（**① 引かれる数 a に補数を足す．n+1 マス**）→ はみ出した桁を無視（**① 答え．n マス**）→（**② 10進数で確かめる**の表示：「② 10進数で確かめると a−b＝c（答えの2進数）」） | n，n，n+1，n マス |

- 各段は1回目誤り → もう1回．2回目も誤りなら正しい値を見せて次の段へ（結果 `ok1`／`ok2`／`rev`）．空のマスがあるときは「あとNマス入れよう」と返し，**試行に数えない**．
- 誤りのマスを赤にし，文でも「右から2桁目と4桁目がちがいます」と言う（色だけに頼らない）．1回目の誤りでは見立て（短いヒント）を1つだけ出す．見立ての一覧は `binary-calc-core.js` の `HINTS`（A-c1〜A-c3，A-a1・A-a2，X-i1・X-i2，X-p1・X-p2，C-s1・C-s2，C-z1・C-z2）．
- 画面の文：補数の段は「① …」，確かめは「② …」．「繰り上がり」「はみ出した桁（を無視する）」を使う．

## 4. 入力欄：1ビット1マス

- マスは `<input>`．0 と 1（全角の０１も受け，半角にして入れる）以外は受け付けず，マスを一瞬赤くして「0 か 1 を入れよう」と出す（試行に数えない）．
- 段が始まると**右端のマス**にフォーカス（向きは rtl）．1文字入れると左のマスへ進む．左端では進まず上書き．まとめて入れたときは §1.1 (b)（そのあとは ltr）．
- Backspace：値があれば消してそのマスに留まる．空なら，rtl では右のマスへ戻ってそのマスを消し，ltr では左のマスへ戻って消す．行が空になったら rtl・右端のマスへ．Delete はそのマスを消す．← →：1マス移動（向きは変えない）．Home／End：左端／右端（rtl に戻る）．Tab：行全体で1つの停止位置．**Enter＝答え合わせ**．貼り付けは受けない．
- IME：keydown では 0／1 以外を止めない．値は `input` と `compositionend` で正規化（NFKC）して，0／1 以外は捨てる．
- 8ビットは4ビットずつの間を空ける．足し算・補数で引き算の左端は「はみ出す桁」の枠（補数で引き算の和の行では入力マス．別の色）．

## 6. 記録（localStorage）

- キー：`csMathTrainer.binaryCalc.v1`．読み書きはすべて try/catch で囲み，使えなくてもその場限りで動く．
- 構造：`{"v":1,"sel":{"kind","bits"},"rec":{"calc4":{tried,perfect,streak,cleared,pending,stage:{…}},…}}`（種類 `calc`／`comp`／`viacomp` × ビット数 4／8 の6つ）．
- 連続正解の ✓：足し算 3 問，補数 3 問，補数で引き算 2 問．**全段 `ok1` の問題だけ**数える．離脱（種類・難易度の切替，戻る，再読み込み）で 0．✓ は消えない．
- 読み込み時の検査：壊れた JSON は初期状態．数でない・負の値は 0，巨大な値は 1,000,000 で頭打ち（連続は ✓ に要る本数で頭打ち）．知らない項目・知らない段は捨てる．誤りの数は回数を超えない．`pending=true` は連続を 0 にする．
- 「記録を消す」は画面内の確認（最初のフォーカスは「やめる」）．
