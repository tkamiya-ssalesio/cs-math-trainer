## 0. 何を固定し，何を変えるか

2進数の小数と10進数の小数を，紙の方法どおりに，**1段ずつ**答えて変換する練習．

| 固定するもの | 変えるもの |
|---|---|
| 10進数→2進数の方法（紙）：**小数部分に2を掛けることをくり返し，整数部分を上から順に並べる**．小数部分が 0 になったら終わり | 変換する数（初級＝小数第4位まで，中級＝整数部分つき） |
| 2進数→10進数の方法（紙）：**1 になっている位の位取りの値を足す**．位取りは 2⁻¹（0.5），2⁻²（0.25），…（指数が1つ減ると，値は半分） | 向き（10進数→2進数／2進数→10進数．サブメニューで選ぶ） |
| 段の手順（下の §3）．1回目の誤りでヒント1つ→2回目の誤りで正しい値を見せて次の段へ | 数の大きさ（難易度） |
| 画面の用語：「小数部分」「整数」「整数部分」「×2 の答え」「位取り」 | — |

**固定の決定（博士 2026-10-22．変えない）**：
1. サブメニューは「解説／10進数→2進数／2進数→10進数」．
2. 10進数→2進数の段：×2 の縦計算の各行で，「×2 の答え」（例 1.25）と「整数」（1）を入れる．**次の行の小数部分（0.25）はアプリが「整数を取った残り」として写す**．最後に答え 0.□□□ を 1 マス 1 ビットで入れる（整数を上から順に並べる）．
3. 2進数→10進数の段：① 位取りの表の**全部の位に欄**を置き，1 になっている位に位取りの値（0.5・0.125 など）を入れる（**0 になっている位は空欄が正解**．博士の決定 2026-10-23．§8-5 の変更）→ ② その和を入れる．
4. 難易度は初級・中級の 2 つ．初級＝小数第4位まで（16 分の 1 刻み．0.0625〜0.9375 の 15 通り．紙の大問3 と同じ範囲）．中級＝整数部分つき（整数部分 1〜15，小数部分は第4位まで．例 4.75＝100.11．15×15 通り）．
5. 終わらない小数（0.1 など）は**解説だけ**で見せる（0.1 の ×2 を 6 行見せて「同じ並びがくり返して終わらない」）．練習には出さない．
6. 解説の順：2³＝8 → 2²＝4 → 2¹＝2 → 2⁰＝1，指数が1つ減ると値は半分 → 2⁻¹＝0.5，2⁻²＝0.25，2⁻³＝0.125，2⁻⁴＝0.0625 → 位取りの表 → 2進数→10進数の例（紙の 0.111・0.0101 など）→ 10進数→2進数の考え方と例 0.625（紙と同じ）→ 0.1 が終わらないこと．生徒は負の指数を授業の［2］で初めて習うので，2⁻¹ などを使う前に「指数が1つ減ると値は半分」を示す．「0 乗が 1」は，この規則（2¹＝2 から1つ減ると半分の 1）で示す．数学的な定義の議論はしない．

**扱わないもの**：第10回の大問4・5 の語（禁止語の一覧は `binary-fraction-core.js` の `BANNED_*` に置く．このファイルにも README にも書かない．自己検査が両方を読んで確かめる），終わらない小数の練習，負の数，16 進数，整数の変換の新しい手法（整数部分の変換は既習の位取り 8・4・2・1 で考える）．
**作らないもの**：時間制限（タイマー・コンボ・スコア），対戦，教員画面，ランキング，「全部クリア」の判定，自由入力の電卓．

## 2. 問題の生成規則

整数部分 I と小数部分 k/16（k は 1〜15）の組．値は N＝I×16＋k を 16 で割った数．**初級は I＝0**（0.0625〜0.9375 の 15 通り），**中級は I が 1〜15**（225 通り）．2 つの向きで同じ集合を使う．

- 10進数→2進数：題は 10 進数（0.625，4.75）．答えは 2 進数．小数部分の 2 進数は，末尾の 0 を付けない（0.75＝0.11）．整数部分は，上の桁の 0 を付けない（4＝100）．紙の書き方（4.75＝100.11）にそろえる．
- 2進数→10進数：題は 2 進数（0.1001₍₂₎，100.11₍₂₎）．
- **出題の重み**：一様（15 通り・225 通りから 1 つ）．ただし**直近 5 問（同じ向き・同じ難易度）と同じ問題は出さない**（初級は 15 通りしかないので）．行数（1〜4 行）の割合は一様の結果に任せる（初級：4 行 8 通り・3 行 4 通り・2 行 2 通り・1 行 1 通り）．
- 乱数は `Math.random`（自己検査だけ種つき）．

## 3. 段の一覧と判定

各段の正解は，生徒の前の段の答えではなく**模範の値**で定める．段が解決したら（正解でも，値を見せても）その段は模範の値に差し替えて鍵をかけ，次の段は模範の値の上から始まる．

### 3.1 10進数→2進数

| 段（チップの名前） | 入力 | 内容 |
|---|---|---|
| 整数部分（**中級だけ**，最初の段） | 整数部分の桁数ぶんのマス | 整数部分を 2 進数に（左の桁ほど大きい位．8・4・2・1） |
| 1 行目，2 行目，… | 「×2 の答え」「整数」 | 小数部分に 2 を掛けた答えと，その整数．**行数は小数部分が 0 になるまで**（紙と同じ．行は最初から全部見えるが，小数部分の欄は前の行が解けるまで空） |
| 答え | ×2 の行数ぶんのマス | 整数を上から順に並べる．中級は整数部分（模範の値）がマスの左に写る |

- 行 r の「小数部分」：1 行目は題の小数部分（0.625）．2 行目以降は，前の行の「×2 の答え」から整数を取った残りを**アプリが写す**（解決した前の行の模範の値から．1.25→0.25）．
- 最後の行が解決したら，結果欄に「小数部分が 0 になったので，ここで終わり」と添える．
- 解決後（最後の段が終わったあと）：「確かめ：0.101₍₂₎ ＝ 0.5＋0.125 ＝ 0.625」を出す（紙の確かめ）．

### 3.2 2進数→10進数

| 段 | 入力 | 内容 |
|---|---|---|
| 位取りの値 | **全部の位**の数の欄（中級は整数部分の 8・4・2・1 の位も）．模範は，1 になっている位が位取りの値，0 になっている位が空欄 | 位取りの表（2⁻¹〜．中級は 2³〜2⁰ も）の，1 になっている位にその位の値を書く（0.5，0.125，4 など）．0 になっている位は空欄のまま（「0」「0.0」も正解）．**全部の欄が空のときだけ断る**．1 になっている位の空欄は誤り（試行に数える） |
| 和 | 数の欄 1 つ | 表に書いた値を足して 10 進数に．式（0.5＋0.0625＝）は段 1 が解けてから出る |

### 3.3 共通

- 各段は 1 回目誤り → もう 1 回．2 回目も誤りなら正しい値を見せて次の段へ（結果 `ok1`／`ok2`／`rev`）．空の欄があるときは「…も入れよう」と返し，**試行に数えない**（**位取りの値の段だけ例外**：全部の欄が空のときだけ断る．1 になっている位の空欄は誤りに数える．§8-5）．
- 誤りの欄を赤にし，文でも「「×2 の答え」がちがいます」「左から2マス目がちがいます」と言う（色だけに頼らない）．1 回目の誤りでは見立て（ヒント）を 1 つだけ出す．
- 模範の値が同じ段でも，位置の違う欄は区別する（欄の名前をラベルにする）．

### 3.4 見立て（1 回目の誤りのヒント）

誤りの型ごとに 1 つ．**ヒントの主張が模範と食い違わないこと**を，自己検査が全数（下の §7）で確かめる（4 つ目の #15 と同じ考え）．ヒントは**条件がそろったときだけ**出し，そろわなければ最後の「見直し」型を出す．

| 段 | ID | 条件（学生の答えが…） | 文 |
|---|---|---|---|
| ×2 の答えが誤り | X-1 | 小数部分そのもの（2 を掛けていない） | 2 を掛けていない．小数部分に 2 を掛けた答えを書く |
| | X-2 | 模範の整数が 1 のとき，整数を取ったあとの値（1.25 でなく 0.25） | ×2 の答えには整数部分も残して書く．整数を取るのは，次の行の小数部分を作るとき |
| | X-3 | 模範の整数だけ（1.25 でなく 1） | 整数だけになっている．×2 の答えは，小数部分も書く |
| | X-4 | 上のどれでもない | 小数部分に 2 を掛ける計算をもう一度やり直そう |
| 整数が誤り（×2 の答えは正解） | I-1 | 模範が 1 で，0 と答えた | ×2 の答えが 1 以上のとき，整数は 1 |

| | I-3 | 上のどれでもない | 整数は，×2 の答えの小数点より左の数 |
| 答え（0.□□□） | B-1 | 模範を逆に並べた形（模範が左右対称のときは出ない） | 整数を上から順に並べる．下から並べていませんか |
| | B-2 | 上のどれでもない | 各行の「整数」を，上から順に見直そう |
| 整数部分（中級の最初の段） | N-1 | 模範を逆に並べた形 | 左の桁ほど大きい位．いちばん右が 1 の位 |

## 4. 入力欄

- **ビット欄**（1 ビット 1 マス．`<input>`）：0 と 1（全角の０１も受け，半角にして入れる）以外は受け付けず，マスを一瞬赤くして「0 か 1 を入れよう」と出す（試行に数えない）．段が始まると**左端のマス**にフォーカス．1 文字入れると右のマスへ進む．右端では進まず上書き．
- まとめて入れたとき（2 文字以上が一度に来る．IME の確定・insertText）：**まとめて来た 0・1 の数がマス数以上なら常に左端から全体を置き換える**．未満なら，フォーカスのマス以降に空きがあるときだけフォーカスのマスから，それ以外は左端から．行の長さを超える分は捨てて「入りきらない分は捨てました」と出す．0・1 以外の文字は飛ばして配る．
- Backspace：値があればそのマスを消して留まる．空なら左のマスへ戻って消す．Delete：そのマスを消す．← →：1 マス移動．Home／End：左端／右端．Tab：行全体で 1 つの停止位置．**Enter＝答え合わせ**（「答え合わせ」ボタンと同じ `check()`）．貼り付けは受けない．
- **数の欄**（「×2 の答え」「位取りの値」「和」）：`inputmode="decimal"`．**数字と小数点だけ**（全角の数字・全角のピリオド「．」は半角に直して受ける．日本語入力のピリオド「。」も小数点として受ける）．それ以外は捨てて「数字と「.」だけ入れよう」と出す．小数点は 1 つだけ．長さは 12 文字まで（`maxlength`）．IME の変換中は触らず，確定で直す．
  - 認める書き方：「1.25」「01.25」「.5」「0.50」「5.」「1」「1.0」「1.00」（値が同じなら正解）．空・「.」だけは誤り（空は試行に数えない）．
  - **判定は文字列を正規形に直して比べる**（`0.1+0.2` のような Number の小数演算で判定・表示を作らない．表示も 16 分の 1 を単位にした整数から文字列を作る）．
- 位取りの値の欄は，最長の値 0.0625（6 文字）が欠けない幅にする（qa-scizor 1周目 Major-2）．自己検査が，全欄の `scrollWidth` が `clientWidth` を超えないことを測る．
- **整数の欄**（「整数」）：数字だけ．2 文字まで．全角の数字は半角に直す．値が同じなら正解（「01」＝1）．
- 数の欄・整数の欄は**自然な Tab 順**．Enter はどの欄でも `check()`（ほかの欄が空なら断って，空いている先頭の欄へフォーカスを動かす．**位取りの値の段だけ例外**：全部の欄が空のときだけ断り，一部の欄を空にしたまま Enter を押すと，1 になっている位の空欄は誤りに数える）．

## 5. 画面の流れ

メニュー（5 つ目のカード）→ サブメニュー（難易度の選択＋解説／10進数→2進数／2進数→10進数．各カードに初級・中級の ✓）→ 解説 または 練習．

練習画面：上に「← 戻る」・向き・難易度．左に作業用紙，右に題・段の指示・段のチップ（✓／×／—）・「答え合わせ」・結果欄．下に折りたたみの「ことば」と「きみの記録」，「記録を消す」．最後の段が解決したら，結果欄に「全段 1回目で正解」か「つまずいた段」を出し，ボタンは「次の問題へ」に変わる（Enter でも次へ．最終段の解決から 0.4 秒は受けない）．答え合わせで画面が上下に動かない（練習画面は上寄せ．結果欄の高さは確保）．

作業用紙：
- 10進数→2進数：（中級）「整数部分 4 → [ ][ ][ ]」の行，×2 の縦計算（小数部分／×2／×2 の答え／整数 の 4 列）の行，答えの行（初級は「0 . □□□」，中級は「100 . □□」）．
- 2進数→10進数：位取りの表（位取り／2進数／10進数／和）．位取りの行は 2⁻¹… （中級は 2³〜2⁰ も）．2 進数の行に題の数字，10 進数の行に**全部の位の入力欄**（0 になっている位は空欄が正解．模範の値を見せるときも 0 になっている位は空欄のまま．欄は点線の薄い色）．和の行は式と入力欄．

### 5.1 解説（各ステップ）

添字 (2) は，紙・スライドの ₍₂₎ と同じ**下付き**（練習画面の題と同じ．指数の 2⁻¹ は上付き）．静的なステップ表示（絵は順に現れる）．ステップ・インジケーター・前へ／次へ・← →（4 つ目と同じ作り）．順（博士の決定 6）：

| # | 題 | 内容 |
|---|---|---|
| 1 | 指数が1つ減ると，値は半分 | 2³＝8，2²＝4，2¹＝2，2⁰＝1．指数が1つ減るごとに値は半分（÷2） |
| 2 | 指数が負の数 | 同じ規則が続く．2⁻¹＝0.5，2⁻²＝0.25，2⁻³＝0.125，2⁻⁴＝0.0625 |
| 3 | 2進数の小数の位取り | 小数点の右の1桁目が 2⁻¹，2桁目が 2⁻²…．整数の位（…，8，4，2，1）も右へ1つ進むごとに半分で，小数点の右でも同じ規則が続く |
| 4 | 2進数→10進数（例1） | 0.111₍₂₎＝0.5＋0.25＋0.125＝0.875（紙の ①）．1 になっている位の値を足す |
| 5 | 2進数→10進数（例2） | 0.0101₍₂₎＝0.25＋0.0625＝0.3125（紙の ②）．0 になっている位は空欄のまま（0 でもよい）．足すのは 1 になっている位の値だけ．表の「足す値」の行の 0 になっている位は，練習画面の空欄と同じ薄い点線の空欄 |
| 6 | 整数部分があるとき | 100.11₍₂₎＝4＋0.5＋0.25＝4.75（「足す値」の行の 0 になっている位は点線の空欄） |

| 10 | 終わらない小数 | 0.1 の ×2 を 6 行．小数部分に 0.2 が2回出た．ここから先は同じ数がくり返される．0.1＝0.00011001100…₍₂₎．同じ並びがくり返して終わらない．**この練習には出ない** |

## 6. 記録（localStorage）

- キー：`csMathTrainer.binaryFraction.v1`．読み書きはすべて try/catch で囲み，使えなくてもその場限りで動く．
- 構造：`{"v":1,"sel":{"kind","lv"},"rec":{"d2b1":{tried,perfect,streak,cleared,pending,stage:{…}},…}}`（向き `d2b`／`b2d` × 難易度 1／2 の 4 つ）．段の記録の名前：10進数→2進数は `int`（中級だけ）・`rows`（×2 の縦計算．行をまとめて 1 つ．1 行でも `rev` なら `rev`，`ok1` でなければ `ok2`）・`bits`，2進数→10進数は `place`・`sum`．
- 連続正解の ✓：**3 問**（どの向きも）．**全段 `ok1` の問題だけ**数える．離脱（向き・難易度の切替，戻る，再読み込み）で 0．✓ は消えない．
- 読み込み時の検査：壊れた JSON は初期状態．数でない・負の値・配列や文字列は 0，巨大な値は 1,000,000 で頭打ち（連続は ✓ に要る本数で頭打ち）．知らない項目・知らない段は捨てる．段の回数は解いた問題の数（tried）を超えず，誤りの数は段の回数を超えない．`pending=true` は連続を 0 にする．
- **別のタブで記録が変わったとき**（`storage` イベント）：このタブも記録を読み直す（向き・難易度の選択はこのタブのまま）．消す前の回数を書き戻さない（qa-scizor 1周目 Minor-4）．解いている途中の問題は，そのまま続けられ，終わったときに 1 問として数える．`?selftest=1` の間は無効．
- 「記録を消す」は画面内の確認（最初のフォーカスは「やめる」．練習の画面（`#bf-play-screen`）の底から 16px 上に重ねて出す．窓の下ではない．style.css の `.screen` の fadeIn が `forwards` で終わり `transform: translateY(0)` が残るため，その画面が `position: fixed` の基準になる（実測：1366×768 で画面の底 655px→箱の底 639px，1024×768 で 652px→636px）．出しても文書の高さは変わらない．文は「このカテゴリ（2進数の小数）の記録が消えます．ほかのカテゴリの記録は消えません」）．このカテゴリの記録だけを消す（4 つ目の記録は別のキー）．消したあとも，選んでいた向き・難易度は保つ．**共用の端末は，次の人に渡す前に「記録を消す」を押す**（README）．
- 入力の長さの上限：ビット欄は 1 回の入力で先頭の 64 文字まで（`cellEdit` の `MAX_INPUT`．`maxlength="64"`）．数の欄は 12 文字，整数の欄は 2 文字．
- `?selftest=1`（値がちょうど 1 のときだけ有効）の間は，記録をメモリ上だけに持ち，端末に書かない．検査中は画面の左下（4 つ目の表示は右下）に「自己検査中：記録は保存されません」と出る．

## 8. 既定で決めたこと（博士に聞かずに決めた．理由つき）

1. **中級の整数部分は，最初の段で 2 進数にして 1 ビット 1 マス．マス数は上の桁の 0 を付けない桁数**（4＝100 は 3 マス）．理由：紙の書き方（4.75＝100.11）にそろえる．4 マス固定だと「0100.11」となり，紙・教科書の書き方と違って混乱する．欠点：マス数で最上位の位が分かる（これは紙の ×2 の行数が先に決まっているのと同じ程度なので許容）．2 進数→10 進数では，整数部分の位（8・4・2・1）も位取りの表に入れる（上の桁の 0 は表に出さない）．
2. **10 進→2 進の中級で，整数部分の変換を「÷2」にしない**．理由：紙の範囲を超えない．整数部分は既習の位取り（8・4・2・1）で考える（ヒント N-2）．
3. **数の欄の書き方**（§4）：同じ値なら正解．全角と日本語入力の「。」を受ける．理由：計算が苦手な生徒にとって，書き方の揺れで×になるのは学びにならない．
4. **判定は Number の小数の計算で比べない**（文字列を正規形に直して比べる）．理由：この単元そのものが「コンピュータの小数の計算が 0.1 を正確に持てない」ことを扱うので，アプリが同じ理由で誤判定したら教材にならない．
5. **全部の位に入力欄を置き，0 になっている位は空欄が正解**（**博士が決定 2026-10-23**．qa-scizor の案．以前の既定「0 になっている位を『—』にして欄を作らない」は，「0 になっている位は足さない」を画面が先に判断してしまい，紙の ②（0.0101）の練習が弱まるので変えた）．決めた細部と理由：
   - 0 になっている位に「0」を書いたら，値が 0 なので正解（「0.0」「.0」「00」も，数の正規形の規則で同じ値 0）．空欄も正解．
   - 断るのは**全部の欄が空のときだけ**（「1 になっている位に，位取りの値を入れよう」）．理由：1 つでも空欄で断ると，どの位が 1 かを教えてしまう．1 になっている位の空欄は誤り（試行に数える）．Enter とボタンは同じ `check()`．
   - 誤りの欄を Z（0 になっている位に何か書いた）・M（1 になっている位が空欄）・V（1 になっている位に違う値）に分け，**すべての欄が同じ種類のときだけ**専用のヒント（P-z／P-m／P-a・P-b・P-c），混ざったときは，Z を含むなら P-d，M と V だけなら P-e（規則だけ言う．P-e は「0 になっている位」の話をしない）．理由：主張が全部の赤い欄に当てはまるようにするため（既存の P-a・P-b・P-c と同じ規則）．ヒントは「0 になっている位は空欄でよい」「空欄にしない」と規則を言い，どの位が 1 かは言わない（題の 2 進数の行に見えている）．
   - 中級の整数部分の位（8・4・2・1）にも同じ規則．
   - 2回目の誤りで模範の値を見せるとき，**0 になっている位は空欄のまま**（「0」を見せない）．理由：1 回目の正解の形（空欄）と解説の「0 になっている位は空欄のまま」にそろえ，0 になっている位に何を見せるかで迷わないため．赤い枠（直した欄）は，書き間違えた欄に付く．
   - 段のチップ・記録（`place` の回数・誤り）・「全段 1回目で正解」の判定は変えない（段の数は同じ）．
   - **言い方**：画面の文・ヒント・指示文・解説・README・SPEC は「0 の位」でなく**「0 になっている位」**（紙の「1 になっている位」にそろえる．「0 の位」は紙・スライドにない言い方で，表の見出しの「2⁰ の位」と混同する．中級の 101.1 で 2¹ に値を書くと「2¹ の位がちがいます」と並んでしまう）．
   - ヒントは，誤りの欄が M と V だけのときは「0 になっている位」の話をしない（P-e）．Z を含むときは P-d．
   - 値を見せたとき，書き間違えた 0 になっている位の欄にも**赤い枠**を付ける（薄い点線の空欄の規則に負けないように）．自己検査が全 480 問の全段で，値を見せた状態の `bf-fix` の欄の枠が赤い実線であることを測る．
   - 読み上げ（aria-label）：値を見せた／確定した 0 になっている位の欄は「空欄のままでよい（0 になっている位）」．
   - **この段だけ Enter の挙動がほかの段と違う**（一部の欄を空にして Enter を押すと，1 になっている位の空欄は誤りに数える）．博士の決めた規則（全部空のときだけ断る）から来る帰結で，挙動は変えない．§9 の 11 で博士に確認する．
6. **最後の段の ×2 の行は最初から全部見える**（行数が紙と同じ）．小数部分の欄だけ，前の行が解けるまで空．
7. **連続正解の ✓ は 3 問**．理由：4 つ目の足し算・補数と同じ．
8. **問題の重みは一様**＋直近 5 問を避ける．理由：行数が多い問題は多いが，それが実際の練習で必要な型．
9. **Enter は常に答え合わせ**（ほかの欄が空ならそれを断って先頭の空欄へ．**位取りの値の段だけ例外**：§8-5）．理由：4 つ目の「Enter とボタンは同じ処理」にそろえる．
10. ヒント文（§3.4）と，解説の言い方（紙とスライドにそろえた）．
